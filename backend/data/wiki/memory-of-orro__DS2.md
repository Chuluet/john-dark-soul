# Memory of Orro (DS2)

thumb|400px
The Memory of Orro is a location in Dark Souls II. It is a fragment of memory of the giant warrior, Orro.

## Description

The memory of the giant that resides in the Forest of Fallen Giants. The Ashen Mist Heart from the Ancient Dragon is needed to enter the memory. The giant is located after the Pursuer boss arena. Only a limited time can be spent in the memory.
