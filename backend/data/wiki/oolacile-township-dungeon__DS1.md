# Oolacile Township Dungeon (DS1)

The Oolacile Township Dungeon is a location in Dark Souls that is part of the Artorias of the Abyss DLC.

## Adjacent locations

Oolacile Township
Chasm of the Abyss

## Description

The Oolacile Township Dungeon is a very short area, containing no loot, supplying the player with a single bonfire which acts as a warping point.

## Enemies

A single, non-respawning Bloathead.
